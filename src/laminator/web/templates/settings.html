Scores

{% call info("i-critic") %}
Off by default
Nothing is written to CriticRating unless you turn this on, because it changes a field on your items.
What it does
When this is on, every time a score is drawn on a poster the same score is also written to the item's CriticRating field in Emby or Jellyfin (0-100, so 7.3 becomes 73). Emby and Jellyfin show it as the critic score and can sort and filter by it.
Safe to use
The field is locked so a metadata refresh does not overwrite it, the previous value is saved, and Restore puts it back. A value you edit by hand in the server afterwards is left alone and reported.
When it takes effect
On the next apply or maintenance run. Turning it off stops further writes but does not remove values already written; use Restore (metadata) for that.

Sign-in and security

{% call info("i-security") %}
Password
One password signs in to this interface. It is stored as a salted hash. Changing it signs out every other session.
Two-factor sign-in
After the password, a 6-digit code from an authenticator app (Google Authenticator, Aegis, 1Password, Bitwarden and others). Turn it on before you make laminator reachable from outside your home network.
Sessions
A sign-in lasts 12 hours, or ends after 2 hours without use. Log out ends it for real. Every sign-in, failed attempt and change here is written to the security log on the Status page.
{% endcall %}
