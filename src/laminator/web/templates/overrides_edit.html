Saving
The file is checked when you save: nothing invalid is ever written. Comments and layout are kept exactly as you type them. The version being replaced is kept as overrides.yaml.prev. Saving changes only this file; nothing reaches your server until you apply it on the Metadata page.
Format
Under overrides:, one entry per item. match says which item (an IMDb, TMDb or TVDB id, or library + title + optional year). Then any of: rating, title, sort_title, original_title, overview, tagline, critic_rating (0-100) and the lists tags, genres, studios (a list replaces everything; {add: [..], remove: [..]} changes only those; [] clears), all written to the server and locked (Emby cannot lock a tagline); and, for the poster only, score (0-10 or short text like A+), template, source and overlay: false. server: emby or jellyfin limits an entry to one server.
Example
overrides:
  - match: {imdb: tt0319343}
    rating: PG-13
    sort_title: "Elf (2003)"
  - match: {library: Movies, title: Dumbo, year: 1941}
    overview: "My own description."
  - match: {imdb: tt0107290}
    tags: [Fan Edit]
    genres: {add: [Holiday]}
    critic_rating: 80
    score: 9.5
