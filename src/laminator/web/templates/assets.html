What this is
A poster you place here replaces the poster {{ srv_label or "the server" }} has as the base laminator draws the score on. It is meant for things the server cannot find the right artwork for, such as fan edits. The poster the server had is kept in the item's poster history, so you can always go back.
Where to put files
In {{ root }} name the poster after the folder the media is in. A movie at /media/movies/Dumbo/dumbo.mkv uses Dumbo/poster.jpg. A show uses its own folder name. You can also keep them per library (Movies/Dumbo/poster.jpg), use a flat file named after the folder (Dumbo.jpg), or, for movies that share one folder, name the file after the movie file. JPEG, PNG or WebP; upper and lower case do not matter.
How it is used
The next run that handles the item (Use custom posters below, a scheduled check, or an apply) makes the file the base poster and draws the score on it. Replace the file and it is picked up the same way. While a custom poster exists it wins over a poster you pick in the server or from the poster chooser.
Removing one
Remove it on the item's page. The file is moved to the trash folder, not deleted, and the item keeps its current base poster until you go back to an earlier one in Poster history.
