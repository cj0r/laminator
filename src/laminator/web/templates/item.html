Written to the server

Critic rating
A number from 0 to 100. When you set one here, laminator stops writing the automatic score into this title's critic rating.
On the poster only
The score (0-100, the same scale as the critic rating: 66 shows as 6.6 on the badge), template and score source for this one title, or no score at all.
