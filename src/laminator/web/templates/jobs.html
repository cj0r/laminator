Runs

{% call info("i-runs") %}Everything laminator does to your server or its own files happens as a run, so you can watch it line by line and look back at it later. Only one run works at a time. A request made meanwhile waits in line and starts by itself; a small one (a single title) goes first, in a gap of the big run, which then carries on. The list below covers runs since the web UI last started, newest first. Open a run to read its log.{% endcall %}

Apply to everything{% if srv_label %} on {{ srv_label }}{% endif %}… {% call info("i-act-apply", "act") %}
What it does
Puts the score badge on every poster in every library of {{ srv_label or "the server" }}. For each film or show it keeps the untouched original poster (saved the first time), looks up the score from MDBList, draws it on that original with the chosen template (never on top of an earlier badge), and uploads the result. A normal metadata refresh in the server leaves it in place. If you turned it on in Settings, the same score is also written to the item's CriticRating.
Safe to repeat
Items whose original, score and template are unchanged are skipped, so running it again only redraws what changed. A poster you picked yourself in the server is noticed and adopted as the new original, and an overlay that a "replace all images" refresh wiped is redrawn.

Run full maintenance now{% if srv_label %} on {{ srv_label }}{% endif %}… {% call info("i-act-maint", "act") %}
What it does
The same pass that runs by itself once a month. First an apply to everything (so scores, template changes and metadata overrides are all brought up to date), then a short summary, then a clean-up.
The clean-up part
Removes saved posters and records of films that stayed missing from the server past the grace period, orphan files nothing refers to, and old caches and exports. Anything that could matter goes to the trash first, where you can restore it.
{% endcall %}
Clean up… {% call info("i-act-clean", "act") %}
What it does
Opens a page that shows exactly what laminator no longer needs (records of films removed from the library, orphan files, old caches) and how much space it takes. Nothing is removed until you confirm there, and a server or NAS that is merely offline never counts as "removed".
{% endcall %}
Restore everything{% if srv_label %} on {{ srv_label }}{% endif %}… {% call info("i-act-restore", "act") %}
What it does
Undoes everything laminator changed on {{ srv_label or "the server" }}: every original poster is uploaded back (the score badges disappear), and every metadata value it overrode, including CriticRating, goes back to what it was, with the locks it added removed.
What it leaves alone
A metadata value you edited by hand in the server afterwards is reported, not overwritten. You get a confirmation page first.

Run history

{% call info("i-hist") %}
Kinds of run
Apply the score overlay… draws badges on posters (one item, one library, or everything). Scheduled check (new or changed posters) is the quick automatic pass: it only handles new items and posters that changed in the server, and skips everything else. Scheduled maintenance is the monthly full pass. Apply metadata overrides writes the values from overrides.yaml to the server, locks exactly those fields and reads them back to confirm. New poster for… / go back to an earlier poster… change one item's poster. Export posters builds the downloadable zip. Clean up and restore from trash remove or bring back leftovers. Backup, verify and restore work on laminator's own data. Restore… undoes posters and/or metadata.
Status
queued: waiting for the run in front of it. running: still working. done: finished without errors. failed: finished with at least one error line; the rest of the run still completed.
Words at the start of log lines
apply a poster was uploaded, render an image was made without uploading, skip nothing was done (the reason follows), lost an overlay had vanished from the server and is redrawn, new you changed the poster in the server and it is adopted as the new original, critic CriticRating updated, restore something was put back, warn / error need your attention.
