What this page is for
Change fields on items that already exist in {{ srv_label or "your server" }} (a different content rating, a sort title, an original title, a description) from a file you keep, overrides.yaml, instead of editing each item by hand. The file is yours: laminator never changes it unless you save it in the editor or add an override from an item's page.
How it works
1. Add an override (on an item's page, or in the editor). 2. This page shows what it would change, field by field, and writes nothing. 3. You review and apply: the old value is saved, the new one is written, exactly those fields are locked so a metadata refresh in the server cannot undo them, and every write is read back to prove it stuck. 4. Restore puts the old values back and removes the locks.
Which items an override matches
By IMDb, TMDb or TVDB id (survives renames and rescans), or by library plus title and year. An entry can be limited to one server with server: emby or server: jellyfin.
