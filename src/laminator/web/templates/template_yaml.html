What this is
The template as plain text, for settings the sliders do not cover or for pasting one you have written elsewhere. It starts from what the Templates page showed when you opened it.
Checked before it is used
Check reads the text, verifies every setting and its range, confirms the font exists and draws a test poster with it. Save does the same check first, and writes the file only if it passes, exactly as you typed it, comments included.
Settings
sources (score providers, first available wins), decimals (1 = 7.3, 0 = 73), gradient (height, max_opacity, color) and score (font, size, color, margin_x, margin_y, embolden, shadow). Sizes are fractions of the poster, so the look is the same on any resolution. Fonts available: {{ fonts | join(", ") }}.
